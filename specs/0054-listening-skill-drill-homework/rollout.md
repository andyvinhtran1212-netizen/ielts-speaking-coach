## Preconditions

Confirm the assigned migration number and base spec, check overlapping Listening and class files with the Black Eye heads, and identify isolated synthetic test classes.

## Staging

Apply the additive migration through the repo runner, deploy the implementation through the staging PR, and test the two classes and public practice against the exact deployed release.

## Production

Use the repository promotion flow after exact staging acceptance and separate production authorization.

## Rollback and repair

Preserve class-linked submissions and playback. Disable new assignments through the UI or roll forward with a repair if live homework already uses the feature. Keep class-aware reads whenever assigned dictation rows exist.

## Observability

Use class tally and persisted attempt references for acceptance. Playback comes from browser events and may be incomplete if the client cannot send a checkpoint. Avoid recording learner transcription or auth data in logs.
