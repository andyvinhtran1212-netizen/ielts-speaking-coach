## Cutover dependency

Migration 295's unique index permits one published package per programme.
`fn_acquire_listening_programme_attempt` requires the target test to remain
published, and `_programme_guided_context` requires the test, package and
exercise rows to remain published. Archiving v1.0 before publishing v1.1
therefore interrupts in-progress v1.0 forms. Submitted review reads historical
exercise rows without a published-status filter, but must still be verified
with a real archived package before release. Owner decision on active attempts
is pending; no status transition is authorized by this draft.
