| Admin mock roster | Distinguish a loading roster from an empty roster. Disable repeat confirmation during save. | An empty roster has no action. Mark the refresh as failed before displaying cached state. | Only an authorized administrator can act. Use the server's eligibility for each sitting. | Keep action and status legible on narrow screens and in supported themes. Give status text a screen-reader announcement after refetch. |

Focus inside the modal on open and return focus to the trigger or row on close. Support keyboard operation and respect reduced-motion settings. |
